Notes:
- First attempt failed with gateway 4014 "Disallowed intent(s)"; resolved by enabling
  the MESSAGE CONTENT (and Presence) privileged intents in the Discord dev portal.
- Wiring: EventHandler::message -> agent::message() (channel id = conversation id),
  proposed actions render as ✅ Approve / ❌ Reject buttons (custom_id
  "approve|reject:<conv>:<action_id>"); EventHandler::interaction_create defers within
  the 3s window, calls agent::resolve(), then edits the response with the result.
- The agent engine (agent::message/resolve) is separately live-proven end to end
  (see artifacts/agent-conversations-e2e.txt); Discord is a thin front-end over it.
